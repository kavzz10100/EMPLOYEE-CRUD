📌 Employee Management System (CRUD)
📖 Project Overview

The Employee Management System is a full-stack web application developed to efficiently manage employee records. The system allows users to perform CRUD operations such as adding, viewing, updating, and deleting employee details through a user-friendly interface.

This project is built using modern web technologies following a modular and scalable architecture.

🚀 Features

✅ Employee Management

Add new employee records

View employee list

View employee detailed profile

Update employee information

Delete employee records

✅ Validation & Error Handling

Required field validation

Duplicate email and phone detection

User-friendly error messages

✅ UI & UX

Responsive design

Scrollable employee table

Fixed headers

Modal-based employee forms

Clean and modern layout
